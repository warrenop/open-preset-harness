## 三层模型

| 层 | 归属 | 生命周期 | 内容 |
|----|------|----------|------|
| **Preset** | Harness `agent-presets` | 单次 session（首轮后冻结） | 工具、人设、prompt |
| **Session log** | Harness `dsh-session` | 单次 session，持久 | 轮次、消息、工具调用 |
| **Project memory** | **本项目** | 项目 repo | 蒸馏事实、领域、决策 |

Preset = 角色。Session = episode。Project memory = 组织知识。

## 依赖关系

```text
@deepseek-ai/cordis
    └── DeepSeek Harness
            └── open-preset-harness
                    ├── dsh-tool-project-memory（Cordis 插件）
                    └── 约定：.dsh/memory/
```

**策略：** Cordis 插件扩展，**不 fork** agent-loop。

## 运行时（Phase 0）

```text
空白 session 启动
  → 读取 index.md（若有）
  → agent.inject 注入索引摘要（一次，有字节上限）

Agent 调用 recall
  → 读盘 + 排序 + 预算截断
  → 工具结果带 path / entry id 引用

Agent 调用 remember
  → 校验 frontmatter + body
  → 追加 domain 或新建 decision 文件
  → 重写 index.md
```

## 与 Harness 其他能力

| 能力 | 分工 |
|------|------|
| AGENTS.md | 静态规范；memory = **已学到的事实** |
| Skills (`.dsh/skills`) | 怎么做；memory = **学到了什么** |
| Session reference | 单次快照；memory = **跨 session 蒸馏** |
| Compaction | 缩短单次 session；memory **跨 session 存活** |
