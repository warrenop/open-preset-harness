# 磁盘格式

[Wiki 首页](../README.md) · Spec：[phase-0-memory-api.md](../../phase-0-memory-api.md) §1–2

## 根目录

```text
<projectRoot>/.dsh/memory/
├── index.md              # 领域目录 + 近期亮点（可注入 session）
├── domains/
│   └── <domain>.md       # 事实日志（append）
└── decisions/
    └── YYYY-MM-<slug>.md # 单条决策文件
```

**projectRoot 解析顺序：**

1. 向上找最近含 `.git` 的目录
2. 否则 session `cwd`
3. 否则进程 `cwd`

## 领域 id

- 格式：`[a-z][a-z0-9-]*`，长度 2–32
- 示例：`security`、`api`、`client`、`onboarding`

## Entry id

```text
mem-<YYYYMMDD>-<6位小写hex>
```

例：`mem-20260818-a3f2c1`

## Frontmatter（必填）

```yaml
---
oph-memory-schema: 1
id: mem-20260818-a3f2c1
kind: fact                    # fact | decision
domain: security
created_at: "2026-08-18T06:00:00.000Z"
summary: "一行蒸馏摘要"
confidence: medium            # low | medium | high
source:
  session_id: "<SessionId>"
  preset_id: "standard"
---
```

## Domain 文件格式

多条 entry 用分隔符 `<!-- oph-memory-entry -->` 隔开（**不要**用 `---` 分隔块，会与 YAML 冲突）。

## Index 注入预算

默认最多 **4096 UTF-8 字节** 的 index 正文注入空白 session（可配置 `indexInjectMaxBytes`）。

## Git 工作流

记忆文件建议 **提交进 repo**，与代码一起 review — Phase 0 的写入治理层就是 `git diff`。
