# 概述

[Wiki 首页](../README.md) · [English overview](../en/overview.md)

## 一句话

**open-preset-harness** 在 [DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek-Harness) 上提供 **项目级组织记忆**：任意 Preset 可写入、任意 Preset 可按需读取，经验不锁在某次会话里。

## 解决什么问题

Harness 正确地把 **Preset（角色壳）** 和 **Session Log（单次对话）** 分开。但团队知识属于 **项目**，不属于某个 Preset 或某次 session。

没有共享记忆时：

- 安全审查每个迭代重复踩同样的坑
- 新人反复问三个月前已答过的问题
- 产品定案随 PM 会话结束而消失
- Token 浪费在「每个角色从零重建上下文」

## 是什么 / 不是什么

| 是 | 不是 |
|----|------|
| 多 Preset 共享的开源项目记忆 | Harness 替代品 |
| 按 **领域** 组织（`security`、`api`…） | 按 Preset id 各记各的 silo |
| 索引 + 按需 `recall` | 每轮灌入整库向量检索 Demo |
| DSH **Memory** 类 Profile Bundle 插件 | DeepSeek 官方产品 |

## 核心概念

```text
┌─────────────────────────────────────────┐
│     项目记忆（共享）                        │
│  index · domains · decisions             │
└──────────────────▲──────────────────────┘
                   │ remember / recall
        Preset A   │   Preset B   Preset C
        Session 1  │   Session 2  Session N
```

**原则**

- 每个 git 项目 **一份** 记忆池
- **Model-visible ⟺ logged**（进模型必进 session log）
- 默认目录：`<projectRoot>/.dsh/memory/`
