# 应用场景

[Wiki 首页](../README.md) · 完整列表：[scenarios.md](../../scenarios.md)

| 场景 | 写入方 | 读取方 | 价值 |
|------|--------|--------|------|
| 跨职能协作 | 任意 Preset | 其他 Preset | 经验不锁在某次会话 |
| 研发 ↔ 测试 | 开发 | QA | 减少反复对齐 |
| 产品 ↔ 研发 | PM | 工程 | 定案与 rationale 可检索 |
| 安全 / 合规 | 审查 | 全部 | 约束自动传播 |
| 新人上手 | 老人长期沉淀 | 新人 | 少打断 senior |
| 开源维护 | Triage | Release | 已知坑与发版惯例 |
| 乙方 / 客户 | 商务 | 交付 | 客户偏好随 repo 走 |
| SRE / 故障 | 复盘 | 排障 | 事故经验复用 |
| 设计系统 | 设计 | 前端 | Token 与例外一致 |
| 数据 / ML | EDA | 建模 | 数据坑留存 |
