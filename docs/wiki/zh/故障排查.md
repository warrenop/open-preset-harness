# 故障排查

[Wiki 首页](../README.md)

## `dsh: pnpm not found on PATH`

**原因：** 未安装 pnpm。

**修复（无需 sudo）：**

```sh
curl -fsSL https://get.pnpm.io/install.sh | sh -
source ~/.zshrc
```

不要用 `corepack enable`（见下条）。

---

## `EACCES: permission denied`（corepack）

**原因：** `corepack enable` 试图写 `/usr/local/bin/pnpm`，需要 root。

**修复：** 改用 [pnpm 官方安装脚本](安装.md#1-安装-pnpm无需-sudo)，或 `npm install -g pnpm --prefix "$HOME/.local"`。

---

## `zsh: no such file or directory: path:packages/...`

**原因：** 安装命令里 `#main&path:...` 的 **`&` 未加引号**，shell 把命令拆成后台任务。

**修复：**

```sh
dsh plugin --profile web add "github:warrenop/open-preset-harness#main&path:packages/tool-project-memory"
```

## `--dump-config` 看不到插件

| 现象 | 处理 |
|------|------|
| 无 `dsh-tool-project-memory` row | 确认 profile 正确（web vs headless 是不同 profile） |
| 装在了 web，跑的是 headless | 在对应 profile 各装一次 |
| patch 未生效 | `dsh --profile web --dump-config \| grep tool-project-memory` |

---

## `remember` 写盘失败 / 找不到 memory

| 现象 | 处理 |
|------|------|
| 无 `.dsh/memory/` | 先 `remember` 一条或检查 `memory_status.initialized` |
| cwd 无 `.git` | `project_root` 回退到 cwd — 看 `memory_status.project_root` |
| readOnly 模式 | patch 里 `readOnly: true` 会禁用写入 |
