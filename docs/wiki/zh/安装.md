# 安装

[Wiki 首页](../README.md) · [English](../en/installation.md)

## 前置条件

| 项 | 要求 |
|----|------|
| Node | ^22.19 或 >=24 |
| DeepSeek Harness | 已安装 `dsh` CLI |
| **pnpm** | `dsh plugin` 依赖 pnpm |
| Git 项目 | 用于解析 `projectRoot`（最近 `.git` 祖先） |

## 1. 安装 pnpm（无需 sudo）

**不要用** `corepack enable`（在 macOS 上常因 `/usr/local/bin` 权限报 `EACCES`）：

```sh
curl -fsSL https://get.pnpm.io/install.sh | sh -
source ~/.zshrc
pnpm --version
```

备选：

```sh
npm install -g pnpm --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
```

## 2. 安装插件（Profile Bundle）

**必须用双引号** 包住 GitHub 源（`&` 否则被 zsh 当后台符）：

```sh
dsh plugin --profile web add "github:warrenop/open-preset-harness#main&path:packages/tool-project-memory"
```

Headless / CI：

```sh
dsh plugin --profile headless add "github:warrenop/open-preset-harness#main&path:packages/tool-project-memory"
```

本地 clone：

```sh
dsh plugin --profile web add ./packages/tool-project-memory
```

## 3. 验证

```sh
dsh --profile web --dump-config | grep dsh-tool-project-memory
```

在 git 项目里冒烟：

```sh
cd your-project   # 需含 .git
dsh --profile web --cwd . "调用 memory_status，再在 onboarding 域 remember 一条测试事实。"
ls .dsh/memory/
```
